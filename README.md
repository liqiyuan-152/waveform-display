# waveform-display

A configurable waveform display component built with Vite, TypeScript, D3 and SVG.

## Features

- Pure display, no interaction
- Single or multiple waveform series
- Configurable frame border/background
- Configurable waveform color, width, line type and opacity
- Configurable point style
- X/Y axes
- Grid lines
- Zero reference line
- Title
- Per-series style overrides
- `updateData()`, `updateOptions()`, `destroy()`

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```
