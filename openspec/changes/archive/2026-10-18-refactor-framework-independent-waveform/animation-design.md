## 状态与渲染连接

每次提交建立独立规范化快照，复制用于动画的点数值、点 ID 和样式，不在 RAF 中引用调用方可变点对象。外部修改原数组不自动生效；显式 updateData（包括同引用再次提交）仍重新规范化，不能仅依赖引用相等跳过。相同目标判断只用于跳过不必要的动画，不能跳过配置存储、订阅变化或既有 forceLayoutChange 语义。更换 onLayoutChange 即使画面相同仍发送规定的布局通知；更换动画回调保存给后续批次。相同目标判断比较规范化点值/身份和影响绘制的配置（函数按引用），每次提交至多线性扫描，不在每帧深比较。

业务 Model 和目标 Layout 在 update 返回前提交；动画只持有短生命周期的 presentation 快照，不改原始数据、默认配置或隐藏序列状态。渲染流程为 Model → 目标 Layout → AnimationPresentation → Views。每个实例的 Animator 合并为至多一个待执行 RAF，帧回调只更新表现几何和依赖视图，不重复 normalize、配置解析或业务布局通知。

通过目标元素 ownerDocument.defaultView 获取时钟、RAF、visibilitychange 和 matchMedia。没有成对 RAF/cancelRAF 时直接最终态；销毁清理全部 RAF、计时器和监听器，并阻断回调重入导致的后续绘制。共享引擎代码不等于共享实例生命周期。

## 首期配置与 API

动画配置是本次新增接口：animation 和 animationUpdate 各自支持 enabled（默认 true）及 onComplete/onAbort，只有总开关打开且类别开关打开才启动。开关从 false 改为 true 不重播已显示序列，仅影响后续变化；关闭某类别收敛该类别的局部效果；若该类别拥有共享坐标域时间线，则将共享域同步收敛到目标，其他类别在该目标域继续局部效果。关闭总开关收敛全部。仅更改动画时长/缓动时不重启当前批次，新配置用于后续批次。animationThreshold 必须为有限非负整数，0 表示全部静态降级；回调必须为函数。

WaveformOptions 新增 animationEnabled（默认 false）、animationThreshold（默认 10000）、animation（入场）和 animationUpdate（更新）。启用后入场默认 1000ms/cubicInOut、delay 0、staggerDelay 100ms、left-to-right；更新默认 300ms/cubicInOut。方向支持 left-to-right/right-to-left/center-out。duration 为 0 立即最终态且忽略 delay；非法非有限或负时间、非法方向/缓动在更新前抛错，不中断已有动画。阈值统计所有规范化有效点，点数大于等于阈值直接最终态；该保守默认需基准验证后才能调高。

公开 chart.animation 控制门面：pause()、resume()、finish()、isRunning()。暂停保持当前表现帧；resume 仅解除手动暂停，隐藏文档仍保持暂停。finish 同步绘制最新目标、释放当前动画且只发出一次本批完成回调。正常完成每个入场/更新批次调用其配置 onComplete 一次；被新更新替代或 destroy 时调用 onAbort 一次，不补发 onComplete。控制器内部可保留按对象句柄和 abort，但首期不公开底层任意 track/globalAnimator，避免扩大公共 API。isRunning() 在存在未终结批次（包括延迟、手动暂停和文档隐藏暂停）时返回 true，表示尚未稳定；idle/完成/中断后返回 false。重复 pause/resume/finish 对空批次无副作用。

首次被静态降级、关闭或零时长配置阻止的动画不建立批次，也不触发动画回调；只有实际开始的批次才拥有完成/中断通知。同一业务目标的活动动画被关闭、环境降级或导出强制收敛时按完成结束；若提交了不同数据目标，则旧批次按中断结束，即使新目标因阈值而不创建动画。非销毁路径的回调执行在最终帧绘制或中断清理后；destroy 先冻结全部批次并释放资源，再最多通知各类别一次 onAbort，不发送 layoutChange 或完成事件。回调创建新批次时旧批次不得再覆盖新状态，回调销毁实例立即停止剩余工作。异常按现有事件异常报告策略处理。销毁后四个控制方法均抛出明确错误。

## 过渡、接管和失效

- 入场：新有效序列使用独立裁剪区，错峰按有效序列顺序；点标记与曲线共享裁剪。
- 更新：按下节的新旧数据差异规则关联序列和数据点，生成等长起点/终点数值几何，不直接插值 SVG path 字符串；点数变化本身不是降级条件。仅匹配不可靠或拓扑不兼容时降级。
- Y 域变化：曲线、轴、网格与零线共享同一帧比例尺；相应刻度同步派生。布局留白采用目标布局，不按帧反复测量；若新旧 plot 矩形的位置或尺寸不同，当前次更新整体静态收敛，不承诺在绘图区移动时保持连续几何。此限制会使自动留白因位数变化而变化的数据更新跳过动画；Demo 必须同时展示固定/协调留白下的过渡与自动留白变化时的降级，不能只展示能动的样例。X 域在同一坐标系下允许过渡，X/Y 比例尺和相关轴、网格共同更新；轴集合或绑定变化直接收敛，避免坐标系不一致。
- 连续更新：先验证新输入，再从当前可见表现接管；旧批次 abort，旧 RAF/完成回调不覆盖新版本。已有交叉淡入淡出被接管时先收敛旧目标再创建新过渡，始终限制为一组旧新层。
- resize、图例切换及显式 render：收敛当前批次后静态呈现最新状态，不自动重播入场。数据与配置同时变化只建立一个业务版本，可包含一个入场类别批次和一个更新类别批次；各类别共享帧调度与坐标系。
- prefers-reduced-motion 或阈值降级：直接目标态；同目标运行中触发立即完成并清理；不同数据提交仍按旧批次中断、新目标静态处理。visibilitychange 仅暂停时间线，恢复不计算隐藏时长，也不解除手动暂停。

## 数据变更动画：参考 ECharts 的差异匹配

补充参考固定 ECharts 提交 34f4d927eafe251f26f63afd3aeefa30f2feba30 的 [lineAnimationDiff.ts](https://github.com/apache/echarts/blob/34f4d927eafe251f26f63afd3aeefa30f2feba30/src/chart/line/lineAnimationDiff.ts) 与 [LineView.ts](https://github.com/apache/echarts/blob/34f4d927eafe251f26f63afd3aeefa30f2feba30/src/chart/line/LineView.ts)。前者通过 add/update/remove 分类，把新点投影到旧坐标系并按新数据顺序生成起终点；删除点不进入新折线。后者停止旧动画、更新数值点阵，并在大幅几何差异时跳过动画。以下是本库适配规则，不宣称逐项复现 ECharts。

新增 animation/presentation/SeriesDiff、PointDiff、GeometryTransitionPlanner 职责模块。匹配与插值在提交时准备，每帧仅消费结果，时间复杂度以线性匹配为目标，不做两组数据的全量两两比较。

| 变化 | 匹配及表现策略 |
| --- | --- |
| 稳定唯一序列 ID 重排 | 按 ID 保留身份，按规范化后的 order 排序结果更新绘制顺序；未指定 order 才按输入顺序，不能忽略当前 order 契约 |
| 序列 ID 缺失 | 仅旧新均为一条无 ID 序列时允许匹配，WaveformPoint[] 保持当前合成 series-0 身份；显式单序列无 ID 使用专用内部键，不与用户 ID 混淆；多序列缺失/重复 ID 时整次数据更新静态呈现，不让部分序列使用目标域、其他序列使用帧域；不猜测身份 |
| 同一序列点值变化 | 优先用点 ID；未使用点 ID 时用唯一 X，匹配到的点从当前表现移动到新值 |
| 新增点、删除点、滑动窗口 | 以新数据顺序建立等长起终点阵列；匹配点用当前位置，新点从其在旧比例尺的投影开始，删除点不再进入新折线；点标记同步增删 |
| 新增序列 | 使用入场配置与错峰；不让未变化的旧序列重播入场 |
| 删除序列 | 使用更新时长淡出；立即从业务状态和布局计算移除，仅保留不可交互旧几何，终态清理 |
| 相同输入值重复提交 | 不新建动画，不重播入场，不重复完成通知；正在运行的同目标动画继续 |
| 点匹配不可靠或曲线类型改变 | 使用整条曲线交叉淡入淡出；无有效数据则清空并取消相关任务 |

WaveformPoint 新增可选 id?: string，normalize 必须保留它；唯一性作用域为序列内部，空白 ID 视为缺失。一个系列的旧新点全部具备唯一有效 ID 时按 ID 匹配（X 值可变化）；所有点均无 ID 时才使用唯一 X。点 ID 混合或重复，或无点 ID 模式下重复 X 导致匹配歧义时不按索引硬配，采用淡入淡出。不对近似 X 做容差猜测。最终连线顺序沿用规范化结果，不能为动画重新排序业务数据；匹配顺序改变可能造成交叉时整条曲线淡入淡出。

对于可靠匹配的点，先将当前表现反投影到当前帧比例尺对应的数值，再同时插值数值与新旧 X/Y 域（坐标域进度限制在 [0,1]，不允许 back/elastic 等缓动使域越过终点或塌缩），最后使用本帧比例尺投影；新增点以新值在旧域投影起步。该规则避免数据变化与轴变化重复投影。曲线、点、轴、网格和零线共用本帧尺度，固定域保持固定。域方向发生改变或插值域不可逆/不有限时直接最终态，不尝试穿过零跨度。当前布局变化仍使用目标留白；容器 resize 走静态收敛规则。

连续更新从当前表现接管，不从上一次业务起点重新播放。最多保留一组旧新表现层，删除序列若在淡出期间以同一 ID 返回则取消淡出并从其当前表现接管。每次更新只有一个版本所有者，旧回调不得覆盖新状态。先提交新版本、移交几何及任务所有权再派发旧批次 onAbort；回调内更新会创建更高版本，外层返回后须检查版本并停止其未执行工作。不允许先调用旧 onAbort 再无条件提交原计划的新状态。新增序列使用入场批次回调，保留及删除序列使用更新批次回调，各类别每次提交最多完成/中断一次；被更高版本或销毁打断的剩余旧通知可丢弃，遵循下文版本终止规则。

极端位移降级：匹配点的屏幕位移超过目标绘图区对角线的 4 倍或投影非有限时，同步最终态；这是本库相对视口的保守策略，不复制 ECharts 的固定 3000px 常量。阈值、reduced-motion 与缺失 RAF 的静态降级优先于所有动画策略。

## 更新分类及冲突优先级

所有提交先验证新配置，失败时旧动画不变。成功提交按下列顺序决定行为，不能通过调用不同入口绕过优先级：

| 条件 | 当前批次 | 新状态与动画 |
| --- | --- | --- |
| destroy | 中断并清理，拒绝复活 | 不建立新状态 |
| 显式空数据/全部无效数据 | 中断 | 立即空态，无新批次 |
| 不同数据目标（含同时修改配置） | 中断 | 按新目标检查降级条件，满足条件才创建新批次 |
| 同一数据目标但关闭总开关/类别、降低阈值或 reduced-motion 生效 | 完成相应活动批次 | 收敛目标，遵循类别共享时间线规则 |
| 仅轴域 min/max 修改 | 中断被替换的域/更新批次 | 允许兼容域过渡；方向或布局变化则静态 |
| 仅样式/刻度/格式化/布局修改，或 resize/render/图例操作 | 完成活动批次 | 静态应用新配置和布局 |
| 仅改变 duration/easing/delay/staggerDelay/direction 或回调 | 保持当前批次的配置快照 | 配置保存给后续批次，不重播 |
| 完全相同的规范化目标与配置（含回调引用） | 保持 | 不建立新版本或额外通知；单独更换回调不属于本行 |

因此，“关闭动画”和“提交新数据”同时发生时，旧动画中断、新数据静态；不会先完成旧目标再把完成通知误认为新数据完成。新版本一旦使旧通知失效，按版本规则丢弃未派发通知。全局降级优先于单序列淡入淡出。

## 共享时间线及结束语义

每个业务版本最多一条共享坐标域时间线，由 animationUpdate 的 duration/easing 驱动，入场时长只驱动各序列裁剪。新增序列若与旧序列域更新并存，其完整目标数据投影到每帧共同坐标系后再应用自己的裁剪。若更新类别关闭、时长为零或被降级，共享域立即目标态，入场仍可按自身配置运行。首次初始化没有旧域，不创建域过渡。

结束条件以参与任务为准：入场类别等待最后一条延迟序列完成；更新类别等待几何、退出和共享域任务全部完成，各类别最多一次终止通知。有坐标域任务但没有可匹配曲线时仍可建立更新类别。没有任何实际任务就不创建批次。

所有强制终止先进入内部 terminating 屏障并解除帧任务，禁止同一批次重复终止，再尝试目标绘制；绘制成功后才将批次标记 FINISHED 并派发完成回调。绘制失败则标记 ABORTED，按动画执行异常规则报告，不发送完成通知。中断路径无需最终绘制，直接清理并标记 ABORTED。terminating 是内部瞬时状态，不新增公开状态 API；用户回调始终在状态已终结后执行，避免 finish 回调递归 finish/export。多个类别同次终止时按入场、更新顺序派发；若前一个回调销毁实例或提交更高业务版本，则丢弃尚未派发的旧版本通知。同一批次不会因为已标记完成而再次收到 onAbort。destroy 的中断通知允许在资源清理后执行，但不得通过该已销毁实例建立任务。

## 空数据、样式及表现内存边界

清空全部有效数据优先于删除淡出：立即显示现有空态、取消当前批次，不保留孤立旧曲线；仅删除部分序列且还有有效可见序列时淡出。隐藏序列不启动几何动画；图例引起的更新继续按静态收敛处理。仅样式、格式化、刻度策略/间隔、字体或布局配置变化不新建动画，先收敛当前批次后静态应用；仅显式轴 min/max 变化且坐标系和绘图区不变时可使用更新动画；曲线类型同时随数据改变时使用整条淡入淡出。已存在动画时仅更换回调或时长不重启，活动批次仍使用启动时的回调快照。

每个匹配序列最多两份几何缓冲和至多一份退出快照；旧快照不能递归持有历史版本。总保留点数预算为 20000（默认阈值的两倍，内部限制，不新增公共配置；animationThreshold 调高也不能越过此保护），超过预算直接收敛，避免小新数据拖住巨大旧数据。不得仅用新数据点数判断内存降级。

## 导出兼容

toSVGString/downloadSVG 保持同步；运行中先 finish 到最新业务目标并清除过渡层再导出，不导出半截裁剪或双份淡入淡出。由导出触发的完成回调排入序列化完成后的微任务（下载时完成 Blob 创建和下载触发后才派发），以避免回调更新数据改变此次导出目标。未来如需“当前帧截图”或异步等待应另增 API，首期不隐式改变返回类型。

使用可注入时钟验证 0%、中间帧、终态、pause/resume、长帧间隔、连续更新和销毁；参考 tests/animation、tests/chart/nativeAnimation.test.ts、nativeAnimationWindow.test.ts 的案例，适配后在本仓库执行，不把源项目通过情况视为迁移验证。浏览器覆盖方向、虚线、点标记、双侧 Y 轴、reduced-motion、隐藏恢复、跨窗口和导出；固定点数与实例数记录 RAF 数量、节点增长和耗时。关闭动画时全部原有兼容测试仍通过。


## 动画执行异常

自定义 easing 在校验阶段只检查函数类型，不调用用户代码预探测。执行中抛错或返回 NaN/Infinity 时，该业务版本的动画立即中断、释放帧任务并尝试绘制已验证的目标静态状态；在终态可绘制时最多发送一次 onAbort，并通过宿主异步错误报告机制报告异常，不发送 onComplete。有限的超调结果可以用于数据数值插值，裁剪宽度、透明度和域进度均约束到有效范围。若静态绘制本身也失败，停止调度并报告失败，不承诺已经成功绘制；实例仍可 destroy，后续有效更新可以重新构建视图。用户回调异常与动画计算异常分开：前者遵循事件隔离规则，不撤销已完成状态。
