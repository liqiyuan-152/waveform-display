## 文档结构

- design.md 保留总体架构、公共契约与阅读索引。
- animation-design.md 集中动画和数据变更策略。
- axis-design.md 集中刻度和动画帧规则。
- specs/ 是行为验收依据；tasks.md 顺序与依赖对应。

继续采用一个变更管理相关工作，避免把动画接入所需的模型/视图边界拆散；按阶段分别提交和验证。暂不创建更多抽象类或额外业务能力，分页与标注始终不在范围内。

## 后续一致性复审

本轮补充并同步规范的事项：

- 明确入场裁剪与共享域更新各自的时间线所有者，避免两类动画同时驱动坐标轴。
- plot 矩形变化时静态收敛，承认当前目标留白策略的连续性限制，不承诺错误的无缝过渡。
- 终帧复用目标刻度，避免对已 nice 域重复计算步长造成终态不一致。
- 新版本先接管后派发旧中断通知，回调内第三次更新优先；已完成后延迟通知不得被重复终止。
- 精度失败的刻度降级改为明确返回值，不保留“边界或空列表”的实现歧义。
- 专项文档标题层级已整理；新增 acceptance-map.md 列出全部规范场景，均标为待验证。

没有修改组件代码，也没有将规划清单当作已执行测试。

## 更新分类复核

上一轮问题均已落实。本轮修正数据更新与环境降级的终止语义冲突：不同目标中断旧批次，同目标降级才完成；增加明确分类表。刻度/格式化配置变更收敛后静态更新，多序列身份不可靠时整体降级，避免两种比例尺混用。补充新动画配置的局部合并/undefined 清除以及 nice 模式重复标签的显示规则。所有变更同步到 spec、任务和验收映射，不增加组件实现范围。

## 宿主集成边界复审

- 修正 Demo 的轴数组编辑漏洞：普通 patch 规则不能解决 yAxes 整体替换，须维护原始选项草稿，避免只改颜色就固化自动标题默认值。
- 明确 init 复用不是所有权转移；Demo 自有容器被占用时拒绝接管，只销毁自身实例。
- 更新与导出使用实例拥有的 SVG 引用，不能查询容器中的第一个 SVG；补充宿主已有 SVG 场景。
- 公开记录自动留白变化会导致动画降级的体验限制，并要求 Demo 同时展示成功过渡和降级，不能以“支持数据更新动画”掩盖条件。

本轮未增加新的图表 API。进一步浏览器体验与性能结论必须通过实施验证获得，继续增加纯文字约束不能替代这些证据。


## 最终交叉检查

本轮先确认前几轮修改均已存在，再修正三项剩余歧义：动画成功场景明确适用条件；相同目标优化不得跳过更换布局回调的强制通知；补齐自定义缓动异常与静态恢复失败的区别。随后重新对照提案能力、设计入口、专项设计、规范场景和任务映射，未再发现当前范围内明确的阻塞性文档问题。

此结论针对文档一致性及可实施性，不承诺实现没有缺陷。任务 1.4 的实际测试证据、工具链复验、浏览器画面、性能预算和打包消费者验证仍须在实施阶段完成。本变更保持未归档、所有实现任务未勾选。


## 终止状态与反向刻度复核

本轮仅澄清两项现有契约，不新增 API 或业务范围：TickLayout.interval 为正距离，nice 反向域以排序后的边界判断零线；强制 finish 先进入内部终止屏障，绘制成功才标记完成，失败走中断报告，避免此前“先完成后绘制”与异常契约矛盾。设计、规范和现有验收任务已同步。复核这两处与暂停、销毁、导出及 legacy 兼容要求后，未发现其他明确新问题。
