## Context

动机见 proposal.md。创建本变更时，Demo 已有首轮报告、177 项清单及 12 个 App 到 SVG 场景，其中两个以预期失败方式记录缺陷；此前没有其他活动变更。以上为创建时基线，当前修复和验证进度见 verification.md。OpenSpec 使用 spec-driven，文档正文采用中文。

## Goals / Non-Goals

**Goals:**

- 将输入、前置条件、预期 SVG、实际结果和证据映射到单个任务。
- 修复线条及数据点的 undefined 继承，确保 0、false 等有效覆盖保留。
- 对已完成验证、失败和待测保持独立记录，使 OpenSpec 的任务计数可真实反映进度。

**Non-Goals:**

- 本变更不重构配置面板结构，不新增公共方法，不发布版本；用户确认的尺寸语义修正见Decisions。
- 不将既有归档中的测试结论直接视为本变更的逐项通过证据。

## Decisions

1. **原始证据归入变更目录。** 首轮 report.txt、checklist.json、截图移入 evidence/initial/，保留为历史快照；当前执行记录写入 verification.md。tasks.md 展开所有 177 项，浏览器和自动化的覆盖范围分别说明。相比只链接外部临时报告，此方式使任务和证据可一同审阅。
2. **按字段使用 undefined 回退。** 在曲线渲染时分别解析线条和点样式，使用空值回退保留合法的 0 与 false；图例线宽使用相同规则。相比仅从 Demo 删除字段，该修复也覆盖通过公共 API 传入显式 undefined 的消费者。避免在全局数据归一化层偷偷改写调用者数据。
3. **先修复确定缺陷，再扩大矩阵。** 两个预期失败测试先转为普通测试，新增所有单曲线样式的自定义→继承→全局更新回归，检查实际 SVG 属性和路径。单元时钟验证动画时间，浏览器验证真实控件及可见结果。
4. **任务勾选要求实际证据。** 第一轮已有场景可以作为基础，但每项计划要求的边界、恢复、候选项及适用曲线未验证完前，不勾选详细条目。具体判定标准、显示条件和证据层次见 acceptance.md。验证工具接受任务文档不代表功能验收完成。
5. **响应式高度上下限冲突。** 最小高度大于最大高度时拒绝提交并保留上一有效图；相等时允许。Demo草稿在提交前检查，公共API在resolveOptions中检查。
6. **按用户确认补齐尺寸与追加契约。** 正数/px作为固定尺寸，百分比分别参照宿主宽高；拒绝非法值并在提交前校验。固定宽度写入SVG，Demo去掉强制100%宽度样式。百分比刷新由库统一观察，删除Demo重复观察器。追加在当前每条曲线尾部增加1点，保留旧点及曲线配置；版本不再控制点数回绕。无曲线时禁用追加且处理函数拒绝空数组追加，不创建示例；空预览追加使用底层数据并退出预览，其他场景仍可创建示例。

## Risks / Trade-offs

- [jsdom 不具备真实字体测量及像素布局] → 该层只证明属性/几何契约，另记录浏览器截图及尺寸。
- [全局与单曲线覆盖易误判] → 测试数据同时包含继承曲线和显式覆盖曲线，断言互不干扰。
- [自动留白、格式化和退化域会改变期望] → 逐项记录前置条件，避免只以 SVG 字符串发生变化判定通过。
- [177 项包含大量条件组合] → 保持细粒度未完成任务，不把抽查或旧测试总数用作全部完成证明。
- [尺寸校验与固定宽度行为收紧] → README和规范明确auto/em/0等从静默回退改为报错、固定宽度不再拉满；回归验证原子拒绝和默认100%兼容行为。

## Migration Plan

本地执行 OpenSpec 严格校验、针对性测试、pnpm check 和浏览器验证。修复无需数据迁移。若回滚本变更，应一起撤销渲染器、尺寸解析/观察、Demo场景/控件及对应规范和回归修改，避免Demo已删除重复观察器但库未接管刷新等不一致；历史证据保留。全部任务及证据完成前不归档。
