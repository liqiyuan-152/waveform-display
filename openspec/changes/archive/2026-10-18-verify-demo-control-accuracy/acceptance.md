# 验收口径

本文件补充 tasks.md 的共同前置条件及具体判定方法，属于测试设计。对于尚未被已有规范明确的边界，记录“待明确契约”，不能仅因为当前实现如此就签收通过，也不自动扩大产品功能范围。

## 记录与完成条件

每条记录包含：任务编号、运行版本/环境、数据集及曲线/值轴 ID、有效初值、前置配置、输入步骤、独立预期、实际结果、证据路径、结果（通过/失败/待测/不适用）、关联缺陷。某个组合不适用时必须说明原因，并在适用组合补测；整个条目不适用时保留未勾选，先通过范围修订说明原因，不能用“当前看不到”判定控件失效。

- 自动化可验证数值、路径、字段隔离、时间和恢复；真实浏览器验证控件操作、颜色面板/下拉/滑块/步进等入口及可见布局。同一字段多个入口可共享数值断言，但至少一次浏览器确认每种入口的事件绑定和键盘可用性。
- 组件 `$emit` 只证明处理逻辑，不能替代真实下拉候选项点击。浏览器截图只证明捕获时可见状态，不能独自证明动画时长或精确 SVG 属性。
- 预期由固定样例的坐标计算、格式化规则或已有规范产生；仅对比“更新前后有变化”或拿另一个调用相同代码的对象作参考，不足以证明绝对精度。
- 属性/文字：文本和枚举精确比较；CSS 颜色按等价颜色比较。数值计算使用绝对/相对容差，记录具体容差及原因；直写数值应精确一致。SVG 路径按输出舍入精度比较，不能要求任意浮点精度。
- 一项只有其适用候选值、合法边界、非法输入、清空语义、往返恢复及指定对象范围都验证后才能勾选；没有数值边界的文本项用空白、Unicode、长文本替代。详细项与修复项的覆盖可复用同一证据，不重复计算完成数量。
- 阶段 `pnpm check` 只代表当时工作区。最终门禁必须在所有验收/修复结束后重新执行，日志同时记录 Node/pnpm 版本及被验证版本（Git 提交，或提交加未提交差异说明）。
- 控件验收默认从重载后的初始 Demo 开始，先结束当前动画，再记录主题、容器宽高、数据版本、轴模式、手动范围和局部覆盖。每项结束恢复初值；涉及场景计数器时必须重载，不能用“切回原始数据”代替清空全部状态。此为测试准备，不要求产品新增重置按钮。
- 现有规范优先于实现细节；依次查阅本变更 delta、对应主规范、README 的公共行为说明，再观察实现。若相互冲突，登记差异及受影响条目，不能选有利于通过的一方。实现源码只能帮助复现，不能独自充当预期。

## 输入分类与清空

| 字段类型 | 必查输入 | 预期 |
| --- | --- | --- |
| 数值 | 字段允许的正常整数/小数、最小值、最大值（如有）、越界、非有限/非数字、空输入 | 保留允许的精度；step 是步进量，不自动等同只允许整数或其整倍数；允许 0 的字段不回退；非法输入不污染上一有效图表 |
| 可选数值 | 另加清空 | 轴 min/max、tickStep、Y 标题 offset、编号 fontSize 清空应按各字段自动/缺省规则处理 |
| 颜色 | 六位十六进制、带透明度颜色、非法字符串、清空；色板入口 | 校验与有效颜色渲染一致；清空是否允许按字段规则，不与“取消继承”混淆 |
| 文本 | 普通、空白、中文/Unicode、长文本 | 标题/炮号空文本、编号清空、字体回退等分别验证；不能假设所有空文本均报错 |
| 选择/开关 | 全候选值、开关往返、键盘操作 | 状态与实际策略一致；恢复后其他配置不丢失 |
| 尺寸 | 正数/小数、正px、(0,100]%及0/负数/非法单位/非有限值/清空 | 按用户确认的尺寸规范解析；非法值拒绝且保留上一有效图。百分比分别参照宿主clientWidth/clientHeight，0尺寸测量回退800/320；固定宽度同步设置SVG显示宽度，空间不足时Demo可缩小适配 |

非法输入需区分“控件阻止输入”“允许保留编辑草稿但显示错误”“提交后接口拒绝”三个层次；记录实际采用的层次及图表是否保持上一有效值，不要求浏览器必须把 NaN/Infinity 文本保留在数值框。有效编辑后错误提示应能解除。非法提交后还须编辑另一个合法字段，再修正原字段并执行涉及数组替换的操作（如值轴编辑/模式往返），确认被拒绝的值没有经原始选项草稿泄漏到后续patch；可见的无效编辑文本不等于已经提交的有效配置。颜色自身 Alpha 与线条/零线 opacity 分别验收：最终透明度为颜色 Alpha 与对应透明度属性的乘积，不能仅断言其中一个属性。

## 显示条件、优先级与数值判定

| 对象/任务 | 必需条件与具体判定 |
| --- | --- |
| 布局 3.1—3.11 | 分开记录容器尺寸、SVG 屏幕边界、viewBox、绘图区。仅当 responsive.enabled=true 且 width 为百分比时，按 min(maxHeight, max(minHeight, 解析后的width/aspectRatio)) 计算高度；数字、纯数字字符串及px宽度均走固定尺寸分支，使用解析后的height。用户已确认：minHeight === maxHeight 合法；minHeight > maxHeight 必须拒绝并保留上一有效图，且拒绝值不得泄漏到后续提交。手动留白绘图区宽高从总坐标尺寸扣除四边；自动留白是最小约束，不能要求实际留白逐字等于输入。补测冲突、极端留白、窄→宽恢复，并记录错误提示与原图保持结果。 |
| 曲线/点 4、8 | 同时准备继承曲线和显式覆盖曲线。按数据点和比例尺计算目标位置；直线/三种阶梯验证转折点，而非只比较 d 字符串不同。点的 size 对应符号面积规则，不等于所有形状的像素半径。逐条曲线的自定义、继承、全局再更新都验证隔离；0、false、undefined 分开验收。size=0 检查实际符号面积退化为0，不能只看输入对象或 getOptions；visible=false 检查点路径不存在。 |
| X/Y 轴 5 | 显式 step、tickStrategy、范围策略及 min/max 组合分开验证。tickCount 是策略参数，nice 不能承诺恰好生成该数量。检查刻度数值、位置、步长、端点、格式和曲线映射；覆盖小数/科学计数、空/常量/反向域。轴字号/颜色/偏移先确保轴或标题确实显示。 |
| 网格 6 | 公共样式先清除局部覆盖再测；局部宽度覆盖公共宽度。参考轴使用两套明显不同的范围，核对 data-axis-id 及实际 Y 坐标；仅 ID 改变不够。单轴模式确认参考轴控件隐藏，往返后绑定有效。 |
| 零线 6 | 范围跨零只是必要条件；还需符合离边界的阈值策略。使用 -10～10 验证样式，另测端点为0、不跨零、贴近边界和切换参考轴；核对 y=scale(0)。 |
| 标题/炮号/编号 7 | 有效文本、显示开关及可见数据满足前置条件。单曲线会隐藏值轴标题、空数据不显示编号；编号字号、长炮号和 X/Y 标题可按适配规则缩小，检查规则与不越界，不能一律断言输入字号=最终字号。 |
| 图例 7 | 使用至少两条曲线；四角×横纵方向检查外接边界与可点击性，长名称/窄窗口检查截断、换行和遮挡。线长/间距按坐标验证；maxItemWidth 有装饰空间下限，不能要求任意小输入成为实际宽度。点击/键盘切换曲线后检查对应路径、坐标轴和图例状态。 |
| 空状态 7、9.7 | 区分空数组与所有曲线隐藏，分别记录约定；检查空状态开关、文字样式以及退出空预览后原数据/覆盖恢复。 |

上表是需要检查的交互约束，不是已通过声明。单曲线显示策略与尺寸现状参考现有规范/实现，但发现与用户可见契约冲突时必须登记缺陷或明确契约后再签收。

Demo数值控件约束与公共API契约分开记录。例如Demo最小高度输入下限为1，不足以证明公共API的minHeight=0非法；Demo拒绝负留白，不改变公共API允许手动负留白的既有约定。测试表单拒绝时不得顺带收紧库接口，除非另有明确契约变更。

X轴的两个刻度数字段必须分别验收：`xDomainStrategy.tickCount`（策略刻度数）仅参与nice范围扩展；data范围不受其影响，显式min/max默认不参与扩展，开启includeExplicit后才按bounds扩展。`xAxis.tickCount`（刻度数量）用于自动刻度密度，不保证最终刻度、标签或网格恰好等于输入数量；标签可因隐藏端点或碰撞少于主刻度。两字段Demo下限均为1、无显式上限，允许小数，空值非法；域策略计算按整数部分取值，不能因step=1便宣称小数非法。

X轴有效显式tickStep优先于自动刻度和minInterval，但仍受可见容量约束，不承诺任意小步长均逐点绘制。minInterval允许0、空值非法；tickStep必须为有限正数，清空恢复自动刻度。nice主刻度最多100个的安全保证不能扩大为legacy自动刻度的保证。范围min/max允许负数、反向域和相等值；相等端点2/2按退化域规则扩展为1/3，清空分别恢复该端自动求域。独立比较域、主刻度、可见标签和点映射，格式化负数使用实际格式契约的Unicode负号，避免把字符差异误报为求域缺陷。

X轴标题偏移按相对绘图区右边的位置验证；自动留白可同时缩小绘图区，不能将标题屏幕绝对X几乎不变误判为偏移未生效。小偏移还受右侧轴/边框的避让下限约束。标题字号可能因长文本适配而缩小，需检查实际旋转文字边界及与炮号的间隔；输入字号与最终字号不总相等。字重是既有的自由CSS文本字段：SVG保留原属性，浏览器解析bold为700、normal为400，空值或无效CSS文本按继承/默认字重回退。记录原属性及computedStyle，不把CSS回退声称为表单校验拒绝或自定义字重成功生效。

尺寸生命周期还须分别验证：百分比依赖开启/关闭、切为固定宽高、销毁后观察器释放。当前规范要求不依赖容器时释放观察器；不能仅凭尺寸结果正确便签收资源行为。此组合由3.3跟踪。

## 动画与数据场景

- 使用低于动画点数阈值的小数据、固定绘图区和可控时钟进行时序验收，先关闭 reduced-motion 并确认没有隐藏页暂停。原始大数据、超阈值、reduced-motion、自动留白变化另验证允许的静态收敛；静态收敛不能算动画时间通过。
- 每次操作记录动画总开关、类别开关、duration、delay、stagger、方向、缓动、数据版本和降级原因。参数编辑是对后续更新生效，不能默认要求正在运行的动画立即重新计时。
- 时长与延迟的优先级沿用 `chart-animation` 主规范：duration=0 时忽略 delay/stagger 并同步到终态，不创建批次或发送动画完成回调；duration>0 时才按延迟/错峰检查开始时刻。关闭→开启动画不自动重播已有数据；需要新数据或明确点击重播。
- 方向检查起始/中间/终态裁剪；duration 检查0和正值；delay 检查延迟前不推进；stagger 检查相邻曲线开始时刻；linear/cubicInOut 在固定进度点比较理论轨迹。可控时钟精确断言；浏览器耗时记录帧间隔和实际误差，不使用未定义的“肉眼精确”。
- 暂停前先确认动画正在运行，暂停期间几何不变，恢复继续剩余进度；finish 到目标终态且移除临时裁剪/图层，连续更新不被旧帧覆盖。同步导出会收敛到目标态，不能用于观察中间帧。
- 五个数据场景核对点数、窗口范围、X/Y 域、零线与网格同步及最终几何；按每个场景的动画/降级条件判断，不要求所有场景都保持过渡。结束态与相同数据和配置的静态结果比较。

历史“追加点”生成器会重算旧点Y，点数按10+version%10回绕。用户已明确要求保留旧点持续追加，新增规范据此替代历史现状：每次在当前每条曲线尾部增加1点，全部既有点、曲线身份/覆盖/绑定不变，经过10/20/30不回绕；从原始或其他场景追加也不先换数据。任务9.21按新契约验证完整点击序列、ID/坐标及中间帧/终态；其他场景仍共用version，9.22—9.25记录前次场景。生成器单测通过不等于完整Demo交互及动画已签收。另须区分“存在但点集为空的曲线”“当前曲线数组为空”及“仅开启空预览但仍保留底层数据”：前者首点X=0已定义；用户已确认后两者分别为：无曲线数组时禁用追加按钮，不自动创建示例；空预览但底层仍有曲线时，追加到底层曲线并退出空预览。其他数据场景仍可从无曲线状态创建示例，不能连带禁用。

9.22—9.25 的最低证据必须分别包含：滑动窗口的旧点淘汰与新点加入（含无残留路径）；坐标域变化中曲线、X/Y轴、网格和零线在中间帧使用同一插值域并在终态一致；极端位移的实际降级条件、有限 SVG 属性和无越界残留；自动留白变化后的绘图区边界、标题/刻度/图例不遮挡及恢复场景。AX 标签变化或场景按钮可用只能作为入口证据，不能替代 DOM/SVG 属性、逐帧记录和截图。

## 证据来源与可复现性

历史证据不得改写以伪装成新执行结果。现有 browser-results.json 包含裁短的路径、未保存稳定曲线ID与完整环境，部分记录没有独立expected；它支持修复前后属性抽查，不是完整几何签收。历史日志缺少源文件指纹，不能事后声称它验证了某个新增版本。

后续每批证据增加清单，记录提交ID、工作区差异及相关源文件摘要、命令、Node/pnpm或浏览器版本、时间、viewport/容器尺寸、主题、reduced-motion和数据集。路径用曲线ID关联，不依赖数组序号识别；保存所需完整路径或可复算的坐标，而非省略字符串。同一次测试的预期、实际、断言和截图使用同一证据编号。环境补录只描述当前环境，不能追认历史运行环境。

OpenSpec 的 status 显示工件齐备只代表计划文档存在；执行进度读取 apply 输出的progress和tasks.md。本变更当前执行进度以最新审核记录为准。

## 归档条件

177 项基础目录不是完整组合数。额外交互入口、跨字段组合和视觉条件也属于其对应条目的完成范围。新缺陷须登记复现步骤、期望、实际、优先级、修复/复验任务；新增范围须同步清单与计数。仅当详细任务和最终门禁都完成、没有未解决契约歧义或缺陷时归档。

值轴标题空值或纯空白会回退绑定曲线名称；标题单位独立于刻度轴头单位，分别验证。左右标题offset清空恢复自动位置，偏移按相对绘图区边界计算。长标题及单位保留全文，以配置字号为上限适配绘图区高度，上下各保留2px；可用高度不足时字号可为0，缩短文本或扩大绘图区后重新计算并恢复字号。

零线dash沿用自由SVG/CSS文本契约：空值/空白、none恢复实线，非负数列（含小数、逗号、奇数项及百分比）按浏览器规则解析；负数或非法CSS文本保留原始属性，浏览器回退none，不视为表单拒绝或成功生效的自定义虚线。分别记录raw与computedStyle，并验证不修改曲线几何及恢复4 4。
