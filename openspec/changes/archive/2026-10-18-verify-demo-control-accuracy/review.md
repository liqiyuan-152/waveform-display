# 文档语义审核

日期：2026-10-18。范围：tasks.md 为主，对照提案、设计、规范、验证记录及实际字段定义。前两轮文档审核仅修改文档，未重新执行产品测试；后续执行任务的产品修改与实测结果见verification.md“执行批次1”。

## Findings

1. **高：缺少可执行的判定标准。** 原任务大量使用“核对 SVG 数值或文字”“输入边界值”，未说明刻度数量是目标参数、点大小是符号面积、自动留白是最小约束等语义，容易把任意变化误判为通过。新增 acceptance.md，明确属性、几何、时间及参考样例的独立判定和记录要求。
2. **高：最终验收与阶段检查混淆。** 全量矩阵未完成时，最终门禁10.1—10.3已经勾选，且布局3.3—3.11缺少冲突值、数值width分支、极端留白等组合。恢复这些条目为待完成，保留原有阶段日志；首轮审核时任务进度纠正为9/189。该纠正不否定已通过的434项测试。
3. **中：显示条件和自动适配未定义。** “跨零即可显示”“输入字号等于输出字号”“打开图例即可见”等解读不准确。补充零线边界阈值、单曲线隐藏策略、非空文本、编号和元数据字体适配、图例空间下限，并在规范中限定适用条件。
4. **中：空输入语义缺失。** 原模板把清空与非法输入并列，未区分合法清除范围、恢复自动字号、清空编号和拒绝必填项。补充输入分类和规范场景，不把所有清空统一判为错误。
5. **中：动态控制只有操作名，没有时序与降级期望。** 重写9.1—9.25，补充三种方向、两种缓动、时长/延迟/错峰、暂停恢复、按钮禁用、五种数据场景和静态收敛的具体判定；同步导出不能当作中间帧证据。
6. **中：覆盖与证据边界不清。** 177项是基础目录而非全部组合；组件事件不等于真实菜单点击。补充入口、逐曲线隔离、参考轴实际坐标、图例键盘交互、窄宽视觉回归及证据要求；未完成组合继续保留待办。
7. **低：基线叙述已过时。** design.md 的“当前未归档变更为空”改为创建时基线；verification.md 的“最终命令结果”改为阶段结果，避免与当前活动变更和未完成任务冲突。

## Remaining Decisions

审核时，尺寸字符串（如800px、50%）、0/负尺寸、最小高度大于最大高度及追加标签含义缺少独立产品契约。后续执行中用户已明确尺寸、保留旧点追加以及高度上下限冲突的行为，已写入delta规范；minHeight === maxHeight 合法，minHeight > maxHeight 拒绝并保留上一有效图。相关实现和浏览器证据见 verification.md 执行批次4。

首轮运行 OpenSpec 严格校验与 git diff --check。严格校验只证明结构可解析，不证明语义完整或功能验收完成；首轮CLI进度快照见 evidence/apply-status-reviewed.json，最新记录见第二轮审核。

## Findings — 第二轮

1. **高：已完成项的证据弱于任务声明。** 2.2宣称覆盖数据点size=0，但测试只断言输入对象为0，未检查实际符号。恢复2.2为待完成，并新增2.6补强独立几何预期；此前相等路径的相对断言仍可证明部分继承一致性，不能扩张为绝对几何准确。
2. **高：零时长与延迟语义未对齐主规范。** chart-animation规定duration=0忽略延迟且无批次/回调。补充到验收口径和9.11/9.16，明确开启动画不会自动重播。
3. **中：场景名称被误当作数据契约。** “追加点”场景每次重算旧点Y，点数按10+version%10回绕，所有场景共享计数器。原“原点保留”预期不准确；9.21改为记录身份/坐标/计数器，先明确标签语义，不擅自批准现状或修改产品。
4. **中：控件清单覆盖不等于交互入口覆盖。** 静态检查141个配置字段路径均已纳入原清单，但页签导航及色板Alpha缺少独立执行项。新增9.26/9.27，覆盖焦点、记忆、禁用、恢复及颜色Alpha与opacity乘积。
5. **中：缺少隔离准备和历史证据版本限制。** 新增1.4和证据清单要求，明确重载与切换数据集不等价；历史截短路径和无版本指纹日志不能追认完整验证。
6. **低：进度和证据措辞仍有残留歧义。** verification中的“最终门禁”改为阶段全量检查；首轮9/189保留为历史快照。补上合法清空规范映射，并区分阶段检查与本轮文档校验。
7. **中：个别任务的影响范围和归档范围不准确。** 9.4将轴颜色与曲线映射混写，现区分轴样式和范围变化；9.26区分页签与子分类的键盘规则。10.4原只核对177项，现要求覆盖全部新增验收项及未决契约后才能归档。

本轮新增4项任务、重新打开1项任务，当前8/193完成。仅修改文档和审核校验记录，没有新增功能通过声明。结构校验记录见evidence/openspec-validation-reviewed-2.log；进度见evidence/apply-status-reviewed-2.json。


## Findings — 第三轮

本轮仅审核和修改文档，没有修改产品代码或新增功能通过声明。用户已确认的尺寸和追加语义继续有效。

1. **高：响应式分支的文字与新尺寸规范冲突。** acceptance.md仍以“非数值width”划分分支，会误把640px和纯数字字符串判为宽高比驱动。现改为仅百分比width且响应式开启时计算比例高度，明确固定尺寸分支与公式；当时的上下限冲突待明确问题已由用户确认并在执行批次4验证。
2. **中：非法输入恢复只检查当前画面。** 原要求未覆盖拒绝后原始草稿可能影响后续patch的问题。补充跨字段合法编辑、原字段修正和数组替换后的状态检查；3.6跟踪该组合，不宣称OptionsDraft已有事务保证。
3. **中：Demo边界易被误用为公共API边界。** 补充Demo最小高度下限1与API既有minHeight=0、Demo非负留白与API手动负留白的区分；验收不能未经授权收紧公共接口。
4. **中：追加的空状态分支缺少定义。** 空点集曲线首点X=0不等于空数组自动创建两条曲线。记录空数组与空预览追加为待明确契约，纳入9.21；已有两项生成器测试仅证明当前实现的部分行为。
5. **中：尺寸结果与资源释放被混作同一结论。** delta要求不依赖容器时释放观察器，但当前setupResponsive在responsive=true且固定宽高时仍创建观察器。将其作为待验证的实现/规范差异纳入3.3，不提前判为完成；原尺寸用例通过结论保留。
6. **低：历史进度易被读作当前进度。** 第二轮8/193及第三轮15/193均保留为历史快照；当前权威进度以最新 OpenSpec CLI 快照为准（本轮为81/193，112项待完成）。

用户已确认高度上下限规则：相等合法，最小值大于最大值拒绝并保留上一有效图；该规则已写入设计、验收和实现。仍待明确的是无曲线数组/空预览的追加语义。本轮不自行批准当前实现，亦未追加独立任务编号；新增组合归入原3.3、3.5、3.6和9.21，任务总数仍193。

## Findings — 第四轮

1. **高：9.22–9.25 的证据边界仍不足。** 生成器测试可以证明滑动窗口的点淘汰、极端数据的有限性和自动留白振幅变化，但不能证明真实渲染中的逐帧几何、轴/网格/零线共享比例尺、极端位移降级或文字遮挡。已补充 `browser-batch24-animation-scenarios.json` 记录 AX 标签变化，并在 `verification.md` 明确这些任务继续待办。
2. **中：批次23只能证明追加入口稳定。** AX 树不暴露点数和点身份，故 31 次点击证据必须与生成器的完整数组断言配对；文档已明确该限制，未将按钮可用性扩大为 DOM 点数验收。

本轮定向测试 34 项通过，OpenSpec 严格校验通过；当前任务计数以 `evidence/apply-status-execution-batch24.json` 为准，9.21–9.25及其余未完成项保持开放。

补充的 Chrome DevTools 批次27已取得真实 SVG 终态属性，但没有改变上述结论：终态路径、轴标签、网格数量和图框宽度可复核，中间帧仍必须由可控时钟和 DOM 采样证明，不能由终态截图替代。

## Findings — 第五轮执行审核

C-08证明只检查解析函数拒绝越界还不足以签收：同一范围字段中的滑块可将无效raw草稿自动夹值并反向提交。已将Slider输入改为已提交value，新增2.7记录修复和回归，并补充delta中的草稿/滑块隔离场景。修复前全局线条、编号、曲线级透明度3个普通回归均失败，见 `evidence/range-draft-before-batch32.log`；修复后须全部通过才维持签收。新增任务使总数由193变为194，历史计数保持原样。

全局线条继承分支不能只使用初始四条显式覆盖曲线验证，批次30已换用signal/reference继承曲线并以独立公式核对所有路径坐标；App混合覆盖测试同时断言显式同伴隔离。网格方向宽度输入1仅恢复有效外观，不恢复缺省覆盖状态，因此批次31结束时重载并检查方向输入为空、公共宽度再次同步两方向。

## Findings — 第六轮执行审核

1. **中：两个刻度数的职责和计数口径仍可能混淆。** acceptance现分别定义域策略tickCount与轴tickCount，区分数据域、主刻度、可见标签；补充data策略、includeExplicit、bounds的前置条件。不能用标签数等于输入作为精度断言。
2. **中：优先级和安全边界表述不足。** 补充显式step对minInterval的优先级、可见容量约束、nice的100主刻度上限及其不适用于legacy的范围；明确小数合法、必填与可选数值的清空差异。
3. **低：测试预期误用ASCII负号。** 新增X范围测试的`.0f`负数预期改为Unicode负号，与格式化契约一致；没有为通过测试修改产品格式器。

批次33新增3个App回归，浏览器65步/70项断言通过，包含真实候选点击和键盘步进，输入值使用原生setter及input事件；不将脚本输入宣称为真实打字。API仅用于固定两点数据及关闭动画，结束重载恢复4条初始曲线与字段。5.3、5.6–5.11本批签收，当前116/194完成、78项待完成。此为阶段审核与验证，最终门禁及归档继续待办。
